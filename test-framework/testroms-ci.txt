# Test ROMs for the GitHub CI job -- blargg's NES suites, Bisqwit's
# ppu_read_buffer and nestest.
#
# These files are NOT in the repository (see roms/README.md); fetch them
# first, then run the suite:
#
#     make -C test-framework testroms
#
# which is `fetch-testroms.py` followed by run_tests.py with the flags a
# test ROM needs: --test-mode auto (read blargg's $6000 report instead of
# guessing from the screen), --no-input (these ROMs drive themselves) and
# a frame budget big enough for the longest suite. A run stops the moment
# a ROM publishes its verdict, so the budget only bounds the ones that
# never report.
#
# A line may carry per-ROM overrides after " | ". The 2005-era suites need
# test=blargg2005, which reads their result byte at $F8 -- or at $F0 with
# result-addr=0xf0, for the July/September 2005 builds; nestest needs
# test=nestest, because it has no signature and is entered at $C000.
